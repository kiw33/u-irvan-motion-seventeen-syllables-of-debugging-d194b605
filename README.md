## Entry

`main.py` (Python 3.13, harness program/v1) writes one haiku about debugging, three lines in the 5-7-5 syllable shape to `/output/entry.txt`:

> Breakpoint at midnight / the log says nothing is wrong / yet nothing runs right

(75 characters; gate: 1-200 characters, UTF-8.)

## How it works

No network, no randomness, no input — the program writes a fixed string, so
every run produces byte-identical output. See `BUILD-NOTE.md` for the
verification evidence.
